# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.3.0] - 2026-09-25

### Added
- Split into a multi-file project: separate styles, program data and app logic.
- Offline support through a service worker.
- Web app manifest and full icon set for installing on Android and desktop.
- Version number in **Body → Settings**.
- README, license, program documentation and this changelog.

## [1.2.0] - 2026-09-25

### Added
- Edit the type or date of a logged BJJ or CrossFit session.
- Undo after logging or deleting a session.
- Log sessions for a past date.
- This week's sessions listed on the Train screen.

## [1.1.0] - 2026-09-25

### Fixed
- Changes are saved the moment they're made, so closing the app right after logging no longer loses the last entry.

### Added
- Saving is also triggered when the app is closed or sent to the background.
- Saving status in **Body → Settings**.

## [1.0.0] - 2026-09-25

### Added
- 4-day BJJ strength program with set logging.
- Rest timer, stopwatch and interval timer.
- 7-week training blocks with a deload week.
- Weekly load tracking for lifting, BJJ and CrossFit.
- Progress charts and strength-to-bodyweight targets.
- Bodyweight log, backup export and import.
